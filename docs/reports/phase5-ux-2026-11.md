# Phase 5: user experience, 28 November 2026

## How it was checked

A script visited pages at phone width (375 px) and looked for sideways scrolling, controls
without a name, fields without a label, small touch targets and load errors. It covered the
public pages, the signed-in pages with a local demo account, and all ten admin pages with a
throwaway admin on the test database. Desktop width was not re-audited by script.

## Found and fixed

| Found | Fix |
|---|---|
| Form labels not tied to their fields (profile, settings) | `Field` now links label and control |
| Three switches with no name that changed nothing | Removed; replaced by real reminders |
| "Show match start reminders" did nothing | A notification now appears when an unlocked match starts within 24 hours |
| Small buttons on phones | Minimum 36 px |
| Match page had two main headings | One |
| A failed load looked like "no matches" (home, sports, dashboard, free trial, transactions) | Shows the error |
| Seven sports with nothing listed looked available | "Coming soon", sorted last, left out of filters |
| Home ticker listed eight sports | Lists the competitions that have matches |
| No result history | New Results page |
| Long names spilled out of admin catalogue lists | Truncated |
| Main script 564 KB (177 KB compressed) | 290 KB (90 KB): signed-in pages load when visited |

Already present: match search and filters, favourite sports.

## Not checked or not built

- Keyboard-only use, screen readers, and focus inside dialogs.
- Colour contrast on gradient and glass surfaces (the script could only judge flat ones).
- Admin settings was not re-opened after the list fix.
- Real devices and other browsers.
- Reminders are in-app only and appear when the user next opens the site: there is no mail server.
- Favouriting individual matches.
